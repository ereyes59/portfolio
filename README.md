# Erwin Reyes Portfolio

This capstone is a responsive three page portfolio website created with semantic HTML and CSS.

# Pages

-Home
-Projects
-About

# Features

- Responsive layout
- Accessible navigation and form controls
- Keyboard focus states
- Responsive project images
- CSS cascade layers and custom properties
- Metadata and Open Graph information
- Structured data
- In-page project navigation

## Technologies

- HTML5
- CSS3
- GitHub Pages

No JavaScript is required for the functionality of the site.
